# 报告问题

发现任务图编辑器有错误、崩溃或行为不符合预期时，请先搜索[已有问题](https://github.com/arxxyr/task-graph-editor/issues)。没有相同问题，就点击[直接提交 Bug](https://github.com/arxxyr/task-graph-editor/issues/new?template=bug_report.yml)填写表单。提交需要登录 GitHub。

请尽量提供以下信息，让维护者能够复现和定位：

1. **应用版本与运行方式**：发布包名中的 `v...` 版本号；自行编译时提供 Git 提交号，并选择发布包、Release 自行编译或 `cargo run` 开发版。
2. **本机系统与平台**：填写 macOS、Linux 或 Windows 的具体版本和 CPU 架构（`arm64/aarch64` 或 `x86_64`）。macOS 可在「关于本机」查看；Windows 可在「设置 → 系统 → 关于」查看；Linux 可查看 `/etc/os-release`，用 `uname -m` 查看架构。不清楚时填“未知”，不要猜测。
3. **相关运行环境**：界面显示问题可补充 X11、Wayland、远程桌面及显卡信息；SSH、ROS2 或地图问题可补充远端系统版本、ROS2 发行版和相关服务版本。只记录与问题有关的信息，不填写远端地址或凭据。
4. **实际现象和预期行为**：写出界面或终端实际显示了什么，以及你原本希望发生什么。
5. **复现步骤**：从打开应用开始，列出点击、输入和选择的顺序。偶发问题请说明频率和最近一次发生时间。
6. **相关证据**：界面问题可按 `F12` 截图；报错可点击左下角「复制提示」取得完整文字。自行从源码运行时，可用 `TGE_LOG=debug cargo run` 获取更详细的日志，并只截取与问题相关的几行。

提交前，请检查截图、提示和日志，遮盖密码、密钥、令牌、内网地址、机器人任务数据、点位坐标及其他敏感信息。不要直接上传未经脱敏的任务图 JSON、GeoJSON 或整份主控日志。若暂时没有可分享的数据，先描述操作和现象即可。

简短示例：

> 版本 v0.12.1，GitHub macOS 发布包，macOS 15、arm64；远端 Ubuntu 22.04、ROS2 Humble。连接成功后，在参数页打开一个任务图，点选位姿并点击「取底盘」。实际状态栏显示“……”，位姿未更新；预期是更新选中位姿。连续尝试 3 次均出现。已附脱敏截图和相关提示。
