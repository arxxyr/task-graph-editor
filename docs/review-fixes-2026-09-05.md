## 交叉复核补充

- 本地 ssh-agent 使用独立 I/O，Session 超时不能覆盖它。现改为受控协议传输，保留全部身份顺序、
  私钥回退、RSA SHA2 与证书算法；签名回调限定 FFI 边界、配套 C 分配器及 panic 捕获。
- Windows 原子提交测试只编译通用逻辑，不执行 Unix 系统调用脚本；Windows agent 另有 5 个平台回归。
- 文本编辑在动作前完成，避免同帧输入与保存读取旧值；元数据、密码和数值均走真实排程回归。
- 异步粘贴时暂存动作，短时唤醒直至内容落地，再自动继续；断开立即取消旧动作，完成后恢复空闲刷新。
- ROS2 回填保留正在报错的文本，不会用旧模型值覆盖并悄悄解除保存守卫。
